# Standard chess pieces

Artwork by [Colin M. L. Burnett (Cburnett)](https://commons.wikimedia.org/wiki/User:Cburnett), from the [standard transparent chess piece set](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces/Standard_transparent). The artwork in this directory is distributed under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).

The vectors were extracted from the published [Chessboard.jsx 2.4.7 package](https://www.npmjs.com/package/chessboardjsx/v/2.4.7), from `src/Chessboard/svg/chesspieces/standard.js` in its source map. JSX attributes were converted to SVG XML, retaining the original shapes, transforms, and the default renderer’s view box. Bare hexadecimal black fills were written as `#000000` so the native SVG renderer displays them correctly. The [Chessboard.jsx MIT notice](./CHESSBOARDJSX-LICENSE.txt) accompanies the extraction.
